Motion Retargeting User Study

You will compare several versions of the same animated motion, transferred from a source character onto a different target character. Your task is to rank them on three criteria.

What you are looking at

Each page shows one reference video at the top — the original motion performed by the source character. Below it are several versions of that same motion applied to a different target character, each produced by a different method. They are labelled A, B, C… in a random order that changes on every page, so the letters carry no meaning across pages.

What to judge

Overall quality
Your holistic judgement: which result looks like the best animation of this motion on this character?
Self-penetration
Does the character's body pass through itself — hands sinking into the torso, arms clipping through the hips, a limb intersecting the head? Rank the result with the least such intersection first.
Semantic preservation
Is it still recognisably the same action as the reference, with the same intent and characteristic poses? Ignore body shape differences; the target character is a different size and that is expected.

How to rank

Give each version a rank from 1 (best) downward. Ties are allowed and expected — if two versions look equally good to you, give them the same rank. You do not need to use every rank number.

There are no right answers and your responses are anonymous. Nothing is recorded until you press submit at the end. Expect roughly 15 minutes.
